# Cogrid — 多用户共享算力合作社

> 众人拾柴，互惠互利。贡献闲置算力换取份额，有突发需求时按份额调用全网算力池。

Cogrid 是一个开源的"算力合作社"：用户挂机即开始奉献自己的 CPU/GPU 算力（强度可调，不影响本地使用），系统通过 PoA 探针验证真实贡献并累积贡献份额。当用户有短时集中的算力需求时，按份额比例调用全网算力池。空闲算力通过"算力固存"机制转化为持久价值（预计算缓存、社区模型训练、镜像预构建等），不浪费任何一滴算力。

## 核心特性

- **按比例分红**：贡献越多，份额越大，可调用的突发算力越多
- **PoA 探针**：即使全网无人使用任务，挂机节点也凭探针验证持续累积"已验证贡献"
- **算力固存**：空闲算力自动转化为持久产物（预计算缓存、社区模型、镜像预构建），后续可复用
- **强度可调**：保守/均衡/激进三档，Agent 监测本地负载自动收缩，不影响日常使用
- **Docker 执行**：任务以容器提交，CPU/GPU 统一接口，语言无关
- **为协作与中断而设计**：任何阶段可暂停/重启/终止，半成品可被后来者理解和接续

## 快速开始

> 当前处于设计阶段，代码尚未实现。以下为目标使用方式。

```bash
# 克隆仓库
git clone https://github.com/cogrid/cogrid.git
cd cogrid

# 一键拉起本地环境（1 协调器 + 3 Agent + 仪表盘）
make dev

# 在另一终端提交任务
cogrid submit --image my-task:latest --cpu 4 --gpu 1

# 查看你的贡献份额
cogrid status
```

```
 │                         │                          │

 │                         │                          │
 │                         │  PoA 探针 ──────────────►│
 │                         │  ◄────────── 探针结果    │

```
