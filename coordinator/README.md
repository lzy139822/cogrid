# 协调器 (Coordinator)

Cogrid 的中枢服务，负责节点管理、贡献记账、任务调度和算力固存。

## 模块

| 目录 | 职责 | 状态 |
|---|---|---|
| `api/` | REST API 路由 | 待实现 |
| `scheduler/` | 按比例分红调度器（用户任务 + 填充任务） | 待实现 |
| `ledger/` | 贡献值账本（含 PoA 探针成功率） | 待实现 |
| `queue/` | 任务队列 | 待实现 |
| `prober/` | PoA 探针派发与结果收集 | 待实现 |
| `filler/` | 算力固存：填充任务生成与产物管理 | 待实现 |
| `models/` | 数据模型 | 待实现 |

## 接口

协调器对外提供两类接口：

- **REST API**（端口 8000）：供 CLI 和仪表盘调用
- **gRPC**（端口 50051）：供 Agent 调用（节点注册、心跳、任务下发、探针）

协议定义见 `../proto/`。

## 开发

```bash
# 启动开发服务器（热重载）
uvicorn coordinator.main:app --reload --port 8000
```
